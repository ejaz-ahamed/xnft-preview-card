# XNFT Preview Card

NFT preview card component built for the Crio.Do XNFT buildout.

**Live site:** https://xnft-preview-card.pages.dev/

## Features

- Responsive layout for mobile and desktop
- Hover state on the NFT image (cyan overlay with a view icon)
- Hover states on the title and creator links
- Outfit font from Google Fonts

## Built with

- Semantic HTML5
- CSS custom properties and Flexbox
- Deployed on Cloudflare Pages
